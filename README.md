# RupRad 💸

> **Smart Student Money Tracking & Bill-Splitting Dashboard**

RupRad is a student-first personal finance and expense-sharing web application tailored for college life, campus canteens, hostel expenses, and instant UPI bill splitting.

---

## ✨ Features

- **📊 360° Financial Overview**: Real-time tracking of monthly budget limits, total outflows, daily averages, and remaining balances.
- **⚡ Splitz (Campus Bill Splitting)**: Create group expense splits with campus peers, calculate per-person shares, copy instant WhatsApp invite links, and track paid/unpaid status.
- **🏷️ UPI Pay & Quick Note Tagger**: Log UPI transactions with recipient bank details, reference IDs, and custom student notes (e.g., "canteen snacks", "petrol bunk").
- **⏰ Smart Note Reminders**: Automatic alerts for transactions made 3–4 hours ago that are missing notes to prevent forgotten expenses.
- **📈 Spending Velocity & Trends**: 7-day stacked bar charts and category breakdowns across Food, Travel, Study, Entertainment, and Hostel.
- **🎯 Student Budget Health Score**: Dynamic financial health rating (0–100) with personalized saving tips and spending limits.
- **📲 SMS / Bank Statement Sync Simulation**: One-tap simulation of incoming bank SMS alerts parsed into transactions.
- **👤 Student Profile Management**: Customizable name, college, UPI ID, and avatar directly from the sidebar.

## 🚀 Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/chintan-v/Rupee.git
   cd Rupee
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
